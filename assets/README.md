# Aalok Editorial Email Signature Kit

## What's included
- `personal_signature.html` and `ai_assisted_signature.html`: actual HTML table-based email signatures.
- `personal_preview.html` and `ai_assisted_preview.html`: open locally in a browser to inspect.
- `assets/memoji.png`: compact Memoji extracted from the previously approved design.
- `assets/handwritten_flourish.png`: cursive artwork with a hand-drawn underline.
- `*_hosted_template.html`: variants pointing to the GitHub Pages URLs below. These URLs work ONLY after uploading the folder to the expected location.

## Upload
Upload this kit's contents into `assets/email-signature/` in the `aalok-gnlu/aalok-gnlu.github.io` repository. Keep the `assets` subfolder. Wait for Pages to deploy, then verify:
- https://aalok-gnlu.github.io/assets/email-signature/assets/memoji.png
- https://aalok-gnlu.github.io/assets/email-signature/assets/handwritten_flourish.png

The `*_hosted_template.html` files assume exactly these URLs. If you host elsewhere, replace their image URLs. When adding the signature to Gmail, paste rendered HTML rather than the source code; some email clients may change formatting.

## Socials
Social names are **intentionally not linked yet** because the exact LinkedIn, GitHub, X and Instagram URLs were not supplied. Replace their names with `<a href="YOUR-URL">Name</a>` once verified. Do not publish guessed links.

## Compatibility
Designed with table-based layout and inline styles for email compatibility. Genuine background blur, SVG icons and external web fonts are deliberately avoided. Some clients may block images until the recipient enables them. The handwritten line and Memoji are the only two required images. No cross-client rendering test has been performed yet.
